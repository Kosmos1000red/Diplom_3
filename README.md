# Diplom_3 — UI-тесты Stellar Burgers

UI-тесты на Selenium с паттерном Page Object.
Каждый сценарий выполняется в Google Chrome и Mozilla Firefox.

## Проверяемые сценарии

Основная функциональность:
- переход в «Конструктор»;
- переход в «Ленту заказов»;
- открытие деталей ингредиента;
- закрытие окна деталей крестиком;
- увеличение счётчика булочки после добавления в конструктор.

Лента заказов:
- увеличение счётчика «Выполнено за всё время»;
- увеличение счётчика «Выполнено за сегодня»;
- появление номера созданного заказа в колонке «В работе».

## Структура проекта

- `pages/` — Page Object классы.
- `locators/` — локаторы элементов.
- `tests/` — тесты.
- `conftest.py` — фикстуры браузеров, подготовка пользователей,
  удаление пользователей и скриншоты при падении.
- `config.py` — адрес стенда и тайм-ауты.
- `requirements.txt` — зависимости.

## Установка

Необходимы Python, Google Chrome и Mozilla Firefox.
Для генерации отчёта также нужны Allure CLI и Java.

Команды для Git Bash:

```bash
python -m venv .venv
source .venv/Scripts/activate
python -m pip install -r requirements.txt
```

Драйверы подбирает Selenium Manager. В фикстуре включено
игнорирование драйверов из PATH, чтобы избежать использования
устаревшего драйвера.

## Запуск тестов

```bash
python -m pytest tests -v --tb=short --alluredir=allure-results --clean-alluredir
```

## Allure-отчёт

```bash
allure generate allure-results --clean -o allure-report
allure open allure-report
```

## Особенности реализации

- Каждый тест запускается в отдельной сессии браузера.
- Пользователи для оформления заказов создаются через API
  с уникальными данными и удаляются после тестов.
- Вход и оформление заказов выполняются через интерфейс.
- Для ожидания элементов и результатов используются явные ожидания.
- Счётчики заказов сравниваются с исходными значениями:
  на общем стенде возможны заказы других пользователей.
